MalotiTrails Lesotho — Inline CSS Edition

Files included: index.html, destinations.html, accommodation.html, gallery.html, contact.html, and js_script.js.

All custom CSS is embedded in a <style> section inside each HTML page. There is no separate custom CSS file. Bootstrap is still loaded online, and the JavaScript file is kept separately for interactive features.

IMPORTANT — Homepage background image:
The homepage CSS expects a file named mokhotlong.jpg in the same folder as index.html. Put your image there and make sure the extension matches. If the actual file is mokhotlong.png or mokhotlong.jpeg, update url("mokhotlong.jpg") in the <style> section of index.html to match the exact filename.

Open index.html in your browser. Internet access is needed for Bootstrap and the online fonts.
